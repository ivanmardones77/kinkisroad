# Kinkis Road

Prototipo arcade de conducción ambientado en la Barcelona de 1984.

## Jugar

[Abrir Kinkis Road](https://ivanmardones77.github.io/kinkisroad/)

El juego funciona directamente en el navegador. En ordenador se controla con las flechas, `Mayús` para el nitro y `R` para reiniciar. En móvil debe jugarse en horizontal con los controles táctiles.

## Publicación

GitHub Pages sirve el archivo `index.html` desde la rama `main`.
